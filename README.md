# Yandex Cloud Function

Точка входа: `index.handler`.

Основные действия: распознавание паспорта, поиск автомобиля по госномеру, официальный отчёт Автотеки, проверка контрагента, генерация ДКП и предварительная оценка кузовного ремонта.

Подробная конфигурация нового агента находится в `AUTO_AGENT.md`.
